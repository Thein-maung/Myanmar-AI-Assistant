# 🇲🇲 မြန်မာစာ AI Chatbot

မြန်မာစာပါ AI Assistant - Weather, News, Exchange Rates, Calculator

## 🌟 Features
- 🌤️ ရာသီဥတု အချက်အလက်
- 📰 သတင်းများ
- 💱 ငွေလဲနှုန်းများ
- 😄 ဟာသများ
- 💫 စိတ်ဓာတ်တက်ကြွစေသော စကားစုများ
- ⏰ လက်ရှိအချိန်
- 🧮 တွက်ချက်မှုများ
- 🌙 Dark/Light Mode

## 💻 Technology

- Myanmar Unicode Support
